Convene as a desktop app for macOS, Windows and Linux: meetings in a window of their own, with camera, microphone, screen sharing and notifications.

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and later) | `Convene-mac-arm64.dmg` |
| Mac with an Intel processor | `Convene-mac-x64.dmg` |
| Windows 10 or 11 | `Convene-windows-setup.exe` |
| Linux (any distribution) | `Convene-linux.AppImage` |
| Debian, Ubuntu and derivatives | `Convene-linux.deb` |

**First launch.** These builds aren't signed with an Apple or Microsoft developer certificate yet, so the system asks before opening them once:

- **macOS:** open the app, then go to System Settings → Privacy & Security and click **Open Anyway**.
- **Windows:** on the SmartScreen prompt, click **More info**, then **Run anyway**.
- **Linux (AppImage):** make it executable (`chmod +x Convene-linux.AppImage`), then run it.

Android: get the app from the [Android release](https://github.com/amanjhacodes55/convene/releases/tag/android-v1.0.0). Source: [desktop/](https://github.com/amanjhacodes55/convene/tree/main/desktop).
